### Featured Repositories & Projects

#### 🌐 Full-Stack Applications
- **[DOCBOOK](https://github.com/Dharamraj82/DOCBOOK_Frontend)** ([Backend](https://github.com/Dharamraj82/DOCBOOK_Backend)) – Doctor appointment booking and medical record platform built on MERN stack.
- **[Group Video Calling App](https://github.com/Dharamraj82/Group_Video_Calling_App)** – Real-time peer-to-peer multi-user video calling application with WebRTC and Socket.io.
- **[Employees Task Management](https://github.com/Dharamraj82/Employees-task-management)** – Role-based dashboard for assigning, tracking, and managing team tasks.
- **[Note Making App](https://github.com/Dharamraj82/Note-Making-App)** – Full-stack notes application built with Node.js, Express, and EJS.
- **[Build Yourself](https://github.com/Dharamraj82/Build-Yourself)** – Server-rendered web portal for habit tracking and task management.

- **[Bubble Game](https://github.com/Dharamraj82/Bubble-Game)** – Fast-paced arithmetic hit-target game built with Vanilla JavaScript DOM manipulation.
- **[Drag Docs](https://github.com/Dharamraj82/Drag-Docs)** – Interactive canvas notes with draggable card components and physical bounds.
- **[To-do List](https://github.com/Dharamraj82/To-doList)** – Task tracker with local storage persistence and priority filtering.

#### 🤖 AI & Machine Learning
- **[AI-Powered Coder](https://github.com/Dharamraj82/AI-Powered-Coder)** – Code analysis and generation assistant using LLM APIs.
- **[AI Notetaker](https://github.com/Dharamraj82/AI-Notetaker)** – Automated note generation, summarization, and task extraction tool.
- **[Student Performance Predictor](https://github.com/Dharamraj82/Student-Performance-Predictor)** – Python ML model predicting academic performance based on study metrics.
- **[Crop Condition Reviewer](https://github.com/Dharamraj82/Crop-Condition-Reviewer)** – Agriculture data analysis model assessing crop health indicators.

#### 🖥️ Systems & Native Applications

- **[School Management System (Java)](https://github.com/Dharamraj82/School-Management-System-Using-Java-terminal-)** – Object-oriented terminal application for student records and fee tracking.
- **[Network Provided System (Java)](https://github.com/Dharamraj82/Network-Provided-System-Using-JAVA-in-terminal)** – Java CLI network administration and socket communication utility.
